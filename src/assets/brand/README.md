# Marca PLEI

Arquivos oficiais do logotipo. Use sempre estes SVGs; não redesenhe a marca no código.

| Pasta | O que é | Onde usar |
| --- | --- | --- |
| `horizontal/` | Mascote + nome em uma linha | Barra lateral, topo no celular, tela de entrada |
| `empilhado/` | Mascote maior + nome grande ao lado | Espaços mais quadrados: capas, cartazes |
| `centralizado/` | Mascote em cima, nome embaixo | Telas de boas-vindas e vazios centralizados |
| `caixa-alta/` | Nome em caixa alta | Assinaturas e rodapés institucionais |
| `simbolo/` | Só o mascote | Favicon (`public/favicon.svg` é o `petroleo-600`), avatar, espaços pequenos |

Cores de cada versão:

- `principal`: mascote e "PLEI" em petróleo. Padrão em fundo claro.
- `petroleo` e `azul`: tudo em uma cor da paleta.
- `branco`: para fundo petróleo escuro (`panel-deep`) ou `brand`.
- `escuro`: versão para fundo escuro com o nome em petróleo claro.

O laranja da reserva nunca entra na marca.
